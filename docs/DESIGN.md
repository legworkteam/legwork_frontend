# MCM AI 프로젝트 — 디자인 스타일 가이드

Stitch로 생성한 스크린(홈, 아바타 스타일링, 스마트 케어, 로그인, QR 진단 등)을 기준으로 정리한 스타일 가이드입니다.

## 1. 톤앤매너
- **럭셔리 미니멀 에디토리얼**: 여백을 넉넉히 두고, 이미지 중심으로 제품/아바타를 크게 보여줌
- 명품 브랜드 느낌의 **차분하고 절제된 무드** — 화려한 색상 대신 무채색 + 골드 포인트로 고급감 표현
- 텍스트는 짧고 담백하게, 카피는 "디지털 럭셔리의 완성"처럼 감성적인 한 줄 문구 위주

## 2. 컬러 팔레트
| 용도 | 색상 | 참고 코드 |
|---|---|---|
| 배경 (Base) | 아이보리/오프화이트 | `#F9F9F8` |
| 주요 텍스트 / 버튼(다크) | 블랙에 가까운 다크 그레이 | `#1A1C1C` |
| 포인트 컬러 (Gold/Amber) | 진한 앰버/브라운 골드 | `#885200` |
| 보조 배경 (카드 등) | 라이트 그레이 | `#E9E9E7` |
| 부드러운 뉴트럴 | 그레이지 브라운 | `#CEC7C1` |

- 골드 컬러는 강조 배지("Fit: 98%"), 진행률 링, 활성 탭/아이콘, 카드 보더 등 **포인트로만 소량 사용**
- 버튼은 기본적으로 블랙 배경 + 화이트 텍스트(주요 액션), 아웃라인 버튼(블랙/골드 보더)은 보조 액션에 사용

## 3. 타이포그래피
- **로고/헤드라인**: 세리프체 (예: MCM 워드마크, "Smart Care Dashboard" 같은 큰 제목) — 클래식하고 명품스러운 인상
- **본문/UI 텍스트**: 산세리프, 작은 크기(12~14px)로 절제된 정보 전달
- 헤드라인은 굵게(Bold), 본문은 Regular~Medium, 라벨류는 자간을 살짝 띄운 올캡스(예: "BODY SPECS", "OVERALL HEALTH")

## 4. 컴포넌트 스타일
- **카드**: 모서리가 둥근(radius 큼) 화이트/라이트그레이 카드, 그림자 거의 없거나 매우 옅음
- **버튼**
  - Primary: 블랙 배경, 흰 텍스트, 완전 둥근(알약) 또는 큰 radius
  - Secondary/Outline: 화이트 배경 + 블랙 또는 골드 얇은 보더
- **진행률/상태 표시**: 골드 톤의 원형 게이지(%), 배지(알약) 형태로 "98%", "92/100" 같은 수치 강조
- **하단 네비게이션**: 아이콘 + 라벨, 총 4탭(홈/아바타/케어/프로필), 활성 탭만 골드 컬러로 강조
- **상단 헤더**: 심플한 3분할(메뉴 아이콘 - 중앙 로고 - 알림/장바구니 아이콘), 배경은 배경색과 거의 동일한 톤

## 5. 이미지/비주얼 스타일
- 인물(아바타)·제품 사진은 **스튜디오톤의 내추럴한 조명**, 베이지·그레이 배경과 잘 어우러짐
- 실사 기반 아바타 위에 반투명 배지/라벨을 얹어 AI 분석 정보를 표시하는 방식이 반복 사용됨
- 제품 사진은 여백이 넓은 정사각/세로 프레임, 그림자 최소화

## 6. 레이아웃 원칙
- 모바일 앱 기준 세로 스크롤 레이아웃
- 섹션 간 여백을 크게 두어 정보 밀도를 낮게 유지
- 각 섹션 상단에 아이콘 + 소제목(올캡스) 조합으로 구분
